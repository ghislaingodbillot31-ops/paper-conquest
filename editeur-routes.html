Éditeur de routes

Routes · choisissez un chemin puis tracez-le sur la carte

Partez d'un point d'ancrage orange d'une route. Clic gauche : poser un point (angles de 30° obligatoires) · Clic droit : retirer le dernier · Entrée : construire. Départ et arrivée uniquement sur un point d'ancrage.

Posez d'abord une porte sur une route, puis partez de cette porte ou d'une muraille. Clic gauche : poser un point · Clic droit : retirer le dernier · Entrée : valider.

Une tour se pose sur un point orange : angle ou bout de muraille, ou croisement de deux murailles.

Une porte se pose sur un point orange de route. Les murailles partent ensuite de la porte.

Aide

Construire

  • Route : choisissez un chemin (terre, gravier ou pavé), puis tracez-le à partir d'une route existante.
  • Construction : choisissez une catégorie puis un bâtiment ; il se pose sur les cases vertes le long des routes.
  • Cliquez un bâtiment posé pour le déplacer, le pivoter, l'améliorer ou le supprimer.
  • Les bâtiments de récolte ont une zone de travail à définir après la pose.

Raccourcis

  • R pivoter · G quadrillage · Suppr supprimer
  • Entrée valider un tracé · Échap quitter le mode placement
  • En mode placement, les onglets restent libres : on peut changer de bâtiment ou ouvrir l'Aide sans quitter le placement.
  • Ctrl+Z annuler
  • Molette : zoom · glisser dans le vide : déplacer la vue
